agentcam is early. The most useful help right now:

- **Bug reports** with clear steps. [Open an issue](https://github.com/chauhanswapnil/agentcam/issues).
- **Log-format cases** that agentcam reads wrong, as small synthetic logs.
- **Focused pull requests**, one change each.

**Never share real agent logs.** They hold secrets and private code. Don't paste them into issues or pull requests; write a small made-up log with the same shape instead.

## Where to start

- [CONTRIBUTING.md](https://github.com/chauhanswapnil/agentcam/blob/main/CONTRIBUTING.md): setup, checks and pull requests.
- [AGENTS.md](https://github.com/chauhanswapnil/agentcam/blob/main/AGENTS.md): the layout, commands, design rules, and how parsing, the audit and the guard work. Written for people and coding agents alike.

## Security

To report a security problem, see [SECURITY.md](https://github.com/chauhanswapnil/agentcam/blob/main/SECURITY.md). Please don't open a public issue.
